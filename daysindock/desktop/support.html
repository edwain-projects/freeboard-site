Support

Days in Dock Desktop Version is a job tracker and Gantt chart for shipyard periods and refits. It runs on your own computer and works with no internet — everything stays in its folder unless you export, print or copy it.

Need help?

Email support@freeboard.boats with questions, bug reports or ideas. If you're reporting a problem, please include your operating system, the app version (Lists & settings → About) and, if you can, the log files from the app's data/logs folder. Have a look at them first: they can contain job titles and file names.

Common questions

What do I need to run the desktop version?

A 64-bit Windows 10 or 11 computer and Google Chrome. the app opens in its own Chrome window with a separate profile, so it doesn't touch your normal browsing. Versions for macOS and Linux are on the way.

How do I install it?

There is nothing to install. Copy the app's folder anywhere — your documents, a work drive or a USB stick — and double-click the program inside it. No admin rights are needed. To remove it, quit the app and delete the folder.

Where is my data stored?

In the app's folder only: the database in data, your files in documents and the backups in backups. There is no server.

Can several people use it?

Yes, on the same computer. Each person signs in with their own name, so every change is recorded with who made it; admins manage users, settings and backups. Phones on the same network can add notes and photos. The data lives on that one computer: the desktop version is not a shared network database.

Does it sync with the Days in Dock phone app?

No. Days in Dock for iPhone and Android is a separate app that keeps its own projects on the phone, and the desktop version keeps its data on the computer. To add photos from a phone to the desktop version, use phone access (below).

How do backups work, and how do I go back to an earlier version?

A backup is made at start, at exit and once a day while the app is open, whenever something changed. The app keeps every backup of the last 7 days, then one per week for 4 weeks and one per month for 4 months. An admin can restore any of them in Lists & settings → Backups & files; the current state is backed up first, so a restore can be undone.

How do I keep a copy somewhere else, or move to a new computer?

Use Export full backup (Lists & settings → Backups & files) to save everything in one .zip, for example on a USB stick. To move to another computer, quit the app and copy the whole folder.

How do I add photos from my phone?

An admin turns on phone access in Lists & settings → Phone. Show the QR code there and scan it with the phone's camera; the phone then opens the app in its web browser (no phone app is needed), over your own Wi-Fi. The first time, the phone page explains how to install the app's certificate so the connection is trusted. Phone access turns itself off after 12 hours without use (you can change that).

Can I import my existing job list?

Yes, from Excel. Import offers a template with the columns it understands; choose your file, check the preview row by row, and only then press Import.

I forgot the admin password.

Quit the app, open a Command Prompt in the app's folder and run the program with the -reset-admin option. It shows a temporary password; sign in with it and choose a new one.

Windows says "Windows protected your PC".

Windows shows this for programs that arrived by download or e-mail. Right-click the program → Properties, tick Unblock and press OK, then start it again.

It says Google Chrome was not found.

Install Google Chrome. If it is installed somewhere unusual, write its location in data/config.ini as chrome_path=… (an example file is included).
